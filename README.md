# Calculator Master

# Project Description

A simple digital calculator app built inside a virtual machine (`devasc@labvm`) using the Linux terminal. The project features a custom-made calculator master menu that guides you through different math options. Work was organized step-by-step by creating separate branches for each function and combining them using GitHub. Everything was written and edited using the terminal text editor (`nano`), testing each math feature thoroughly to ensure it handles mistakes safely before bringing it all together into the main project.
